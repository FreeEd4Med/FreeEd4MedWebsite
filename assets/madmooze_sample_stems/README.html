MadMooze Sample Stems Pack (Demo)

This small demo shows a suggested folder layout and labeling approach for stems prepared for streaming or clinical delivery.

Demo only: the download contains placeholder text files, not playable WAV stems or an MP3 mix. Do not use it as an audio or clinical resource.

What the ZIP contains

  • 01_drone_vocals_stem.placeholder.txt — placeholder for a lead vocal stem.
  • 02_pad_stem.placeholder.txt — placeholder for a sustained ambient pad.
  • 03_perc_stem.placeholder.txt — placeholder for light percussion.
  • 04_bass_stem.placeholder.txt — placeholder for a subtle bass or low pad.
  • mix_preview.placeholder.txt — placeholder for a low-bitrate audition mix.
  • stems_info.json — example metadata fields for a stems package.

Preparing a real package

  • Supply real stems as WAV or FLAC; use the recipient's requested sample rate and bit depth.
  • Include a README with filenames, intended use, tempo where relevant, and any technical notes.
  • Document ownership, permissions, and any limits on clinical, app, or redistribution use.
  • Follow the recipient's delivery specification and the care team's direction for patient playback.
