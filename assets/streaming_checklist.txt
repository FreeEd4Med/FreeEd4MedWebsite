Clinical Music Delivery - Artist Checklist (MadMoozeMusic / FreeEd4Med)

1) Master: WAV or FLAC at the receiving service's requested sample rate and bit depth.
2) Preview: include a clearly labeled compressed audition copy if useful.
3) Loudness: there is no universal -14 LUFS delivery target. Check the recipient's current specification; measure and document integrated loudness and maximum true peak.
4) Playback level: LUFS is not listening volume. Follow the care team's or facility's guidance for patient playback.
5) Stems: label files clearly (for example, 01_vocals.wav, 02_pads.wav, 03_percussion.wav).
6) Include BPM and sync points only when relevant to the intended use.
7) Add a README with title, artist, intended use, attribution, and license/permission terms.
8) Package the approved master, stems, metadata, and preview together; check links and filenames before delivery.

Music is a supportive resource, not a substitute for medical care. Confirm clinical use and playback requirements with the care team.
