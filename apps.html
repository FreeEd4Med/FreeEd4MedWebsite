FreeEd4Med Media SuperTool desktop app — v5.2.1

A cross-platform desktop app for audio and video creation, with lyric videos, visualizers, audio analysis and mastering, transcription and captions, stem separation, notation, and social-media exports.

Download v5.2.1 (free, about 280–380 MB):

  • Windows (64-bit) installer
  • macOS (Apple Silicon) disk image
  • Linux (64-bit) AppImage

The installers are not code-signed yet, so Windows and macOS may show a security warning on first run; the install steps explain how to continue. Verify your download with SHA256SUMS.txt. See the releases page for release notes and older versions.

The repository hosts installers only; source code is not published. Licensed CC BY-NC-ND 4.0. For questions or commercial-use permission, please contact FreeEd4Med.
